The data format for EasyDynamics is still under development, and input
is welcome.

Currently, the data is stored in an `Experiment` object, and must be a
`scipp.DataArray` with coordinates `Q` and `energy`.

If you have data that you wish to analyse with EasyDynamics, then please
do not hesitate to contact us and we will help create a loader for your
data. This will also provide us valuable information about what kind of
data formats we need to support.
